# Tahee
**Problem Statement**
Localized Filipino tailors (_mananahi_) struggle with informal order tracking and disorganized pickup schedules, often resulting in poor communication with the customers, missed deadlines, and lost revenue from unmanaged rush requests. Without a dedicated tracking system, tailors frequently lose visibility over order completion timelines and daily business performance. 

**Target Audience**
- Local, unknown Filipino tailors
- Customers

**Proposed Solution**
Tahee is a progressive web application that streamlines order management for local tailors (_mananahi_) by providing real-time progress tracking, automated pickup reminders, and intelligent deadline alerts. It professionalizes tailor-client communication with transparent status updates and automated rush-fee calculations, helping tailors eliminate delivery delays and maximize shop earnings.

**Output**
Progressive Web App (PWA)
